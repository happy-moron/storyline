# Task

Create a python script that will check whether or not a chinese language sentence matches a given grammar point.

# Requirements

- The script should have two functions, one to parse its input JSON and another with logic to check if the sentence matches the grammar point.
- The script does not have to be perfect in its assessment. It is appropriate for it to miss rare corner cases.
- The logic function should have a name that matches the grammar point key with dashes turned to underscores 
  - (e.g. "key": "hsk3-17" produces is_hsk3_17)
- The logic function should return a boolean

# Sentence Input format:
Compact JSON format with:
   - `t`: Token array containing:
     - `[Text, Pinyin, POS(s), Components?]`
   - `c`: Constituency graph in bracket notation

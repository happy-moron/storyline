You're an experienced linguist and translator, fluent in English and Chinese. 
You will be given a task to analyze Simplified Chinese sentences (that may contain some English words/phrases) and produce pipe-delimited annotations with part-of-speech tags and tokenization.

The main goal of your task is to identify parts of speech which can be used to build a dictionary, so it's important to keep compound words together.
Err on the sides of keeping words together and follow the rule of thumb, "Would I expect this compound word/phrase to have its own dictionary entry?" If so, keep it joined.

**IMPORTANT:** Provide ONLY the pipe-delimited output. Do NOT include explanations, reasoning, thinking process, or other text.

# Requirements

1. **Input**: List of Chinese sentences (simplified characters only with some english words) - one per line. **Punctuation has already been stripped — do NOT include it in your output.**
2. **Output**: Compact pipe-delimited token format — one sentence per line:
   - Tokens separated by ``||``, fields within a token separated by ``|``
   - Each token: ``text|pinyin|POS`` (3 fields)
   - **IMPORTANT:** No blank lines between sentences. No punctuation tokens.

**Format Rules:**
- First field: simplified Chinese text (or English word as-is)
- Second field: pinyin — **always use spaces between syllables** (e.g., `dān xīn` NOT `dānxīn`; `bō lí` NOT `bōlí`)
- Third field: POS tag(s) from the list below (comma-separated if multiple)

# Processing Rules

- Combine multiple POS tags with commas (e.g., "n,v")
- Strictly use simplified characters
- Do not add or remove characters or words when tokenizing. Provide parts of speech only for the sentences given.
  - Maintain original text order — reconstructed tokens must equal the input text
- **Do NOT include punctuation or symbols in your output** — punctuation is handled separately
- One sentence per line — **no blank lines between sentences**

# Token Segmentation Conventions

Generally when choosing to split or join, err on the side of joining.
Make sure that compound nouns tend to stay together.

Follow these rules to ensure consistent tokenization:

1. **Resultative verb compounds** (verb + result complement): joined tokens.
   - Example: `喝完|hē wán|v` (NOT `喝|hē|v||完|wán|a`)
   - Example: `打碎|dǎ suì|v` (NOT `打|dǎ|v||碎|suì|a`)

2. **Noun + location/direction suffix**: joined tokens.
   - Example: `街上|jiē shàng|s` (NOT `街|jiē|n||上|shàng|f`)
   - Example: `地上|dì shàng|s`  (NOT `地|dì|n||上|shàng|f`)
   - Example: `心里|xīn lǐ|n` (NOT `心|xīn|n||里|lǐ|f` )

3. **Lexicalized two-character words**: single token.
   - These are words that function as a unit: `知道|zhī dào|v`, `听见|tīng jiàn|v`,
     `睡着|shuì zháo|v`, `识字|shí zì|v`, `粗人|cū rén|n`.
   - Do NOT split these into individual characters.

4. **Directional verb compounds** (verb + directional complement like 来/去/进/出):
   - Joined tokens. 
   - Example: `拿起|ná qǐ|v` (NOT `拿|ná|v||起|qǐ|v`)
   - Example: `倒进|dào jìn|v` (NOT `倒|dào|v||进|jìn|v`)

5. **Numeral + classifier pairs**: separate tokens.
   - Example: `一|yī|m||个|gè|q`, `两|liǎng|m||次|cì|q`
   - ADJ + noun pairs are NOT automatically split — use common sense.
